# 日志

## ESP-IDF 的日志等级

ESP-IDF 一共有 **6 个日志等级**：

| 宏             | 等级    | 说明                                                         | 是否常开 |
| -------------- | ------- | ------------------------------------------------------------ | -------- |
| `ESP_LOGV`     | Verbose | 输出高度详细且频繁的调试信息，通常包括内部状态，可能会使输出过于繁杂。 | 通常关闭 |
| `ESP_LOGD`     | Debug   | 输出详细的诊断信息（例如变量值、指针地址等），适用于调试。   | 通常关闭 |
| `ESP_LOGI`     | Info    | 输出描述系统正常运行的一般信息。                             | 默认开启 |
| `ESP_LOGW`     | Warn    | 输出可能引发问题，但已被处理或减轻影响的事件。               | 默认开启 |
| `ESP_LOGE`     | Error   | 仅输出严重错误，这些错误如果不进行干预处理，软件无法自行恢复。 | 默认开启 |
| `ESP_LOG_NONE` | None    | 无日志输出，即完全禁用日志。                                 | —        |
